# 稼轩行迹 · 辛弃疾行迹与词作水墨地图

一个用于中学语文课堂的单页互动项目：把辛弃疾一生中有政治活动或文学创作的地点，收进一张国风水墨地图；
点开墨点看地方与事件，点开事件进入第一人称的「橙光式」互动叙事。

当前完整叙事的只有一首词——**《破阵子 · 为陈同甫赋壮词以寄之》**（淳熙十五年冬，鹅湖之会）。
其余地点保留事件卡片，作为完整的框架与后续扩充的接口。

---

## 打开方式

- **课堂最省事：双击「稼轩行迹」桌面快捷方式**（或本目录的 `一键打开.cmd`）。
  它会优先用 Chrome / Edge 的**应用窗口 + 全屏**打开，没有地址栏和标签页。
  想换回普通浏览器窗口，直接双击 `index.html` 即可。
- **直接双击 `index.html`** 也可（推荐 Chrome / Edge）。全部为本地静态文件，不联网也能用。
- 若浏览器限制本地文件，可在本目录起一个静态服务器，例如：

  ```powershell
  node _build/serve.mjs      # http://127.0.0.1:7801/
  ```

- 课堂投影建议按 `F11` 全屏，或点右上角「全屏」；界面按 16:9 与 1440/1600/1920 宽度做过适配。

## 课堂动线（约 5–8 分钟）

1. **展卷** → 地图全览，右侧是辛弃疾小传与图例。
2. 点**铅山 · 鹅湖**的墨点（带「叙」印）→ 右侧出现「1188 鹅湖之会」。
3. 「先读原词」→ 词作弹窗：十句竖排，点任一句看注释；可「朗读全词」。
4. 「进入互动叙事」→ 六折第一人称叙事：雪夜带湖 → 鹅湖对谈 → 挑灯看剑 → 连营入梦
   → 沙场点兵（含一次选择）→ 醒来作词。词卷会在第六折（醒来）展开。
5. 读完得一枚「阅」印；底部编年条可跳看 1140—1207 的关键年份。
6. 右上「导览」有操作说明，「词作赏析」随时可再打开全词。

键盘：`空格` / `回车` 推进对话，`Esc` 关闭弹层。

## 内容与结构

- `index.html`：开卷页、地图舞台、侧栏、编年条、词作弹窗、导览、互动叙事舞台。
- `css/ink.css`：纸色、墨色、朱印三色的国风样式；地图、侧栏、弹窗、叙事的全部样式。
- `js/data.js`：全部中文内容——11 处地点、13 条编年、10 句词与逐句注释、六折剧情脚本。
- `js/map-geometry.js`：由 Natural Earth 数据离线投影生成的海岸线 / 岛屿 / 河流路径（`window.MAP_GEO`）。
- `js/map.js`：把地图数据画成 SVG（宋金分色、和议界、山峦笔触、四边淡出、地点墨点）。
- `js/rpg.js`：互动叙事引擎（章回卡、打字机、立绘、选项、闪白、词卷、回顾、结局）。
- `js/app.js`：开卷、侧栏事件卡、编年、词作弹窗、朗读、全屏与本地进度。
- `assets/img/`：十张 AI 生成的水墨插画（7 张场景 + 2 张人物 + 1 张开卷封面）。
- `_build/`：生成与验收脚本、提示词、地图原始数据、QA 截图（不参与运行，可删）。

进度（哪些地方读过、哪段叙事看完）存在浏览器 `localStorage`，键名 `xqj.jiaxuan.progress.v1`。
换一台电脑或清缓存后会回到初始状态。

## 地图与史实说明

- 地图是**教学示意图**，不是精确地理图：海岸线与河流取自 Natural Earth（1:50m），
  宋金和议界（大散关—淮河—入海口）为手绘简化；地点按现代经纬度投影后做了少量避让（带湖与鹅湖）。
- 叙事以通行说法为准；个别年代、地点存在异说（如《破阵子》作年 1188/1189），课堂使用时可作讨论。
- 第一人称叙事中「男儿到死心如铁」等句未安到陈亮头上；陈亮卒于 1194，辛弃疾卒于 1207，依史实交代。

## 图片来源与再生成

插画由 AI 生成（火山方舟 Seedream，国风水墨风格）。提示词在 `_build/prompts.json`，
批量生成脚本 `_build/gen-images.ps1`（Windows PowerShell，读 UTF-8 的 JSON 提示词）。
单张重生成：

```powershell
node "C:\Users\31957\.dsh\profiles\web\node_modules\dsh-media-gen\scripts\gen-image.mjs" "提示词" --size 2048x1152
# 上面是本机的 CLI 路径，换一台机器按自己的安装位置替换即可
```

生成结果在 `generate/image/`，选中的图复制到 `assets/img/` 并使用固定文件名：

| 文件 | 用途 |
| --- | --- |
| `cover.jpg` | 开卷页 / 结尾远望 |
| `study.jpg` `door.jpg` `ehu.jpg` | 雪夜书斋、柴门、鹅湖 |
| `sword.jpg` `camp.jpg` `battle.jpg` `wake.jpg` | 挑灯看剑、连营、沙场、醒来 |
| `chenliang.jpg` `xinqiji.jpg` | 陈亮立绘（叙事内）、辛弃疾像（侧栏） |

## 验收记录

1600×900 的各屏截图（开卷、地图、侧栏、词作、六折、选项、词卷、回顾、结局、1920 投影、导览、带湖）
以及 `file://` 直开的自测截图，都在本地 `_build/qa/` 下生成，**未随仓库提交**（体积原因）。
需要时用下面的脚本重新跑一遍：

```powershell
node _build/qa.mjs           # 逐屏截图
node _build/playthrough.mjs  # 从开场自动点完六折，验证无死枝
node _build/file-test.mjs    # 以 file:// 打开并走一遍主流程
```

> 这三个脚本依赖本地 Playwright 与固定的项目路径，仅作开发自检；换环境时需改脚本里的
> `createRequire(...)` 与浏览器 `executablePath`。
